# FOI commons

An archive, and later a searchable database, of statistics released under the Australian Commonwealth Freedom of Information Act. FOI releases are scattered across agency disclosure logs as PDFs; this project collects them in one place, keeps the originals, and (in later phases) pulls the tables out so they can be searched and reused.

**Phase 1 (archive).** From the repo root run `Rscript R/scrape_dss.R` (Department of Social Services disclosure log) and `Rscript R/scrape_servicesaustralia.R` (Services Australia disclosure log). Add a number (e.g. `Rscript R/scrape_dss.R 5`) to test on that many documents. Runs are resumable: re-running skips documents already downloaded and verified by checksum. Right to Know is paused (see `docs/sources.md`).

**Where data goes.** Everything lives under `data/`, which is gitignored: manifests at `data/manifest_<source>.csv` (one row per item and document, every field the source gives, plus fetch time, HTTP status, local path, SHA-256 and size) and downloaded files at `data/raw/<source>/<reference>/<filename>`. Logs go in `data/logs/`.

**Phase 1b (all agencies).** `data/registry/agencies.csv` lists Commonwealth entities and their disclosure log URLs (built by `R/build_registry.R` and `R/discover_fallback.R` from the Australian Government Organisations Register). `R/harvest_log.R <log_slug> <log_url> [agency] [full|html_only] [max_docs] [max_pages]` archives one log (listing HTML, detail pages, every linked document) into `data/raw_html/<log_slug>/<date>/`, `data/raw/<log_slug>/` and `data/manifest_<log_slug>.csv`. `R/run_all.R` walks the registry; `./run_full.sh` runs the whole chain (harvest known logs, second discovery pass, rebuild registry, harvest new logs).

**Run / resume the full archive** (from the repo root): `nohup ./run_full.sh >> data/logs/harvest.log 2>&1 &`. It is safe to stop and re-run: finished logs are listed as `done` in `data/registry/harvest_status.csv` and skipped, and an interrupted log resumes from its open `data/raw_html/<log_slug>/<date>/` folder, skipping documents already downloaded. `Rscript R/run_all.R refresh` re-harvests finished logs into a new dated snapshot; `Rscript R/run_all.R only=<log_slug>` runs one. Progress: `tail data/logs/harvest.log` (a progress line every 10 documents, a summary line after each log, `DONE` at the end of each `run_all.R` pass). Blocked hosts: `data/registry/blocked_hosts.csv`.
